# Contributing to seo-mcp-skills

Thank you for considering contributing!

## How to Contribute
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/new-skill`).
3. Commit your changes with clear messages.
4. Push to the branch (`git push origin feature/new-skill`).
5. Open a Pull Request.

All contributions are reviewed by **Kerwyn Arias** (`ireunlocker`).
